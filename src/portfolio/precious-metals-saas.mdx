## Project: Novem Exclusive Backoffice

### Situation

Novem needed one operational system for precious-metals and cryptocurrency contracts, customers, partners, invoices, payments, KYC workflows, and blockchain integrations.

### Task

Build and maintain a multi-role backoffice connecting customer operations, contracts, payments, banking integrations, and on-chain data across staging and production environments.

### Action

- Built customer, partner, contract, invoice, and payment workflows with role-based access
- Integrated KYC processes, bank APIs, payment transactions, and blockchain data
- Added audit logging, Sentry error tracking, log forwarding, and background jobs
- Supported tokenized precious-metals workflows with daily reconciliation, proof-of-reserves logic, and transaction monitoring
- Added agent login using short-lived signed HMAC tokens with email allowlists, expiry, and replay protection
- Improved CI/CD so documentation, configuration, and workflow-only changes can skip the long test suite while production image builds continue independently
- Worked with staging, production, and pull-request preview environments on DigitalOcean App Platform

### Result

Delivered a central operating platform for sales, customer service, payments, compliance, and blockchain operations across controlled deployment environments.

### Key Innovations

- One operational model for fiat, crypto, and precious-metals contracts
- Role-aware financial workflows and audit trails
- Background processing for payments, invoices, and blockchain synchronization
- Signed, short-lived agent access without weakening the normal login path

### Technologies

Ruby on Rails 7, Ruby, PostgreSQL, Redis, Sidekiq, Webpacker, JavaScript, Web3.js, AWS S3, DigitalOcean, Sentry, Logtail, Papertrail, RSpec, Docker
