## Project: RWA Token Sale and Purchasing Applications

### Situation

The project needed to connect precious-metals token purchases to bank-transfer settlement while keeping pricing, wallet delivery, liquidity, and administrative operations consistent.

### Task

Build focused services and application flows for token exchange, payment initiation, transaction monitoring, and settlement.

### Action

- Connected bank-transfer settlement to token release after confirmed payment receipt
- Added pricing locks to prevent drift during a purchase
- Supported NNN and NVM exchange flows using current product prices from the backoffice API
- Monitored BSC transactions through BscScan over a bounded waiting period
- Added pending, successful, and failed transaction states with timeout handling
- Added Redis caching for frequently requested product prices
- Connected credit-card signup to backoffice user data and transaction status

### Result

Created a token-sale workflow with explicit transaction lifecycles, current pricing, payment verification, and blockchain settlement monitoring.

### Technologies

NestJS, TypeScript, Node.js, MongoDB, Redis, JWT, BscScan API, REST, cron jobs, Jest, Supertest
