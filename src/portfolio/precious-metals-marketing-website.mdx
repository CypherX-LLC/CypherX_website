## Project: Precious-Metals Marketing Website

### Situation

A precious-metals business needed a website that could explain a specialised offering clearly, support campaigns, and remain easy for the content team to maintain.

### Task

Build a fast, flexible marketing website with a separate editorial content layer and a dependable deployment workflow.

### Action

- Built the frontend with Nuxt 3 and static generation
- Connected Storyblok as the headless content-management system
- Configured Netlify for builds, deploy previews, CDN delivery, and atomic deployments
- Structured reusable content blocks so editors could update pages without developer intervention
- Created a publishing workflow connecting content changes and repository changes to reviewable deployments
- Established a foundation for selective incremental regeneration as content needs evolve

### Result

Delivered a maintainable marketing website that combines fast static delivery with editorial flexibility and a repeatable review and deployment process.

### Technologies

Nuxt 3, Vue, Storyblok, Netlify, static generation, CDN delivery, serverless functions
