## Project: Ghostmarket

### Situation

Ghostmarket needed to expand its NFT marketplace beyond Phantasma and support collectors, creators, and liquidity across larger ecosystems.

### Task

Build multichain contract infrastructure that supported marketplace activity across major networks while giving the product team a faster path from feature development to mainnet deployment.

### Action

- Migrated the open-source contract codebase from Truffle to Hardhat for faster testing, deployment, and iteration
- Deployed ERC-721 and ERC-1155 contracts across multiple mainnets
- Built custom marketplace contracts for NFT listing, trading, and settlement flows
- Developed relayer contracts to support NFT market maker activity
- Delivered an SDK so applications could integrate with Ghostmarket's smart contracts across chains

### Result

Created multichain NFT marketplace infrastructure across Phantasma, Ethereum, BSC, Polygon, Avalanche, and other supported ecosystems.

### Technologies

Solidity, ERC-721, ERC-1155, Truffle, Hardhat, smart contracts, relayers, SDK development, Phantasma, Ethereum, BSC, Polygon, Avalanche
