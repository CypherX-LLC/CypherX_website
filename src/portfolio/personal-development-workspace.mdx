## Project: Personal Development Workspace

### Situation

The client needed a practical workspace for personnel development that connected employee context and development requirements with relevant learning records.

### Task

Deliver a hosted full-stack HR application while keeping Frappe LMS as the system for courses and learning activity.

### Action

- Built the frontend with React and Next.js
- Implemented Node.js backend logic and PostgreSQL persistence
- Added user and role structures for the workspace
- Connected the backend to Frappe LMS through its API
- Mapped relevant course, enrollment, and progress information into the workspace view
- Kept personnel-development context in the workspace and learning records in the LMS
- Added Docker and CI/CD foundations, testing, deployment, and technical documentation

### Result

Delivered a maintainable HR development workspace that connected development needs with learning activity without duplicating the learning platform's course and progress model.

### Technologies

React, Next.js, Node.js, PostgreSQL, Docker, CI/CD, Frappe LMS, REST API
